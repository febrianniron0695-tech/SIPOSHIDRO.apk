# SI POS HIDRO — GitHub Pages

Sistem Informasi Pelaporan Stasiun Hidrologi Dinas Pekerjaan Umum dan Perumahan Rakyat (PUPR) Provinsi Nusa Tenggara Timur.

### Berkas Repositori:
1. `index.html` — Aplikasi Web Utama (Lengkap dengan Tampilan + Fitur Laporan + Download CSV)
2. `Kode.gs` — Skrip Backend Google Apps Script
3. `manifest.json` — Konfigurasi PWA Mobile
4. `sw.js` — Service Worker Offline
5. `.nojekyll` — Penanda bypass Jekyll untuk GitHub Pages
